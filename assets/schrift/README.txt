Xharig Sans

xharig-sans-400.woff2 and xharig-sans-700.woff2 are a modified version of
Lato 2.0 (Regular and Bold) by Lukasz Dziedzic, licensed under the SIL Open
Font License 1.1 (OFL.txt in this folder).

Modification: Latin subset, kerning kept, packed as WOFF2 by
tools/schrift_woff2.py. Because the OFL does not allow the Reserved Font
Name "Lato" on a modified version, this version is named "Xharig Sans".
