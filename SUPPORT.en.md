# Getting help and reporting problems

[Deutsch](SUPPORT.md) · **English**

There are three ways. Pick the one that matches your situation — all of them
are read.

## 1. The tool still runs → the red button

**Info → Report a problem.** There is a field for one sentence, the finished
report below it, and a red button next to it. That is all.

The report contains your system, packaging, game state and the most recent
errors — but **no names and no file paths**. You see all of it beforehand, and
nothing is sent in the background.

## 2. The tool does not start → Discord

**[xharig.com/discord](https://xharig.com/discord)**, forum
**Fehler-Melden**. **No GitHub account needed.**

If Verse-Kit does not start at all, you cannot reach the button from way 1. A
screenshot of the error message is entirely enough — it almost always shows
what went wrong.

## 3. You are on GitHub anyway → open an issue

**[Open an issue](https://github.com/Xharig/VerseKit/issues)**. You need to be
**signed in** to GitHub, otherwise the "New issue" button is greyed out — that
looks like a restriction, but it is only the missing sign-in.

The **GitHub issue …** button on the "Report a problem" page inside the tool
puts the report into the form for you.

## What helps most

- **What you did** right before it happened — one sentence is plenty
- **A screenshot**, if something looks wrong
- **The error report**, if you can get to it

## Afterwards

Anyone who finds a bug or suggests something **gets named for it** — in the
changelog and on the thanks page inside the tool.
